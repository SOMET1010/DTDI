# PASS Academy Android v0.3

Build Android propre de PASS Academy pour test sur smartphone.

- application autonome, sans serveur ;
- contenus embarqués dans l’APK ;
- progression stockée localement ;
- six parcours PASS ;
- build reproductible par GitHub Actions.

La branche `pass-academy-v03` produit l’artifact `PASS-Academy-Android-v1.3.0-recette-zero-lecture-01`.
